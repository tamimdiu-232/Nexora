# Nexora
**Next-generation organizational intelligence.**

Upload documents (including scanned PDFs), search them by keyword or meaning, ask questions in Bangla or English and get answers with the exact source page, then have a human reviewer verify them. Role-based access, organization/department isolation and a full audit trail are built in. The demo data in this repository is synthetic.

## What is in this repository

| Folder | Contents | Verified status |
|---|---|---|
| `ai-service/` | Python FastAPI service: PDF extraction, OCR, classification, information extraction, chunking, embeddings, search, RAG Q&A, summarization, related documents | **45 automated tests pass** (run in the build sandbox) |
| `laravel-overlay/` | Laravel application code (auth, roles, organizations/departments, documents, search, chat, review, audit, platform administration, Blade UI + design system, 7 test files + a real-AI integration test) | **Syntax-checked only (`php -l`). NOT executed** — the build sandbox had no Composer/Packagist/MySQL |
| `sample-documents/` | 9 synthetic PDFs (incl. a scanned one and a corrupted one) | Generated by `scripts/make_sample_documents.py` |
| `scripts/` | `setup-mac.sh`, `run-tests.sh`, sample generator | Shell syntax checked only |
| `docs/` | Requirements, architecture, database, API, security, testing, manual, demo script, limitations | Describes what actually exists |

**Please read `docs/TESTING.md` first:** the Laravel half has never been run. Expect to fix a few small issues on first run; see "First run" below.

## Prerequisites (macOS)

- XAMPP (PHP **8.2+**, MySQL/MariaDB). Start **MySQL** in the XAMPP control panel.
- Composer: `brew install composer` (or https://getcomposer.org/download/)
- Python 3.10+: `python3 --version`
- OCR (for scanned PDFs): `brew install tesseract poppler` (Bangla OCR: `brew install tesseract-lang`, then set `OCR_LANGS=eng+ben` in `ai-service/.env`)
- VS Code (any editor works)

## Setup (once)

```bash
cd nexora
bash scripts/setup-mac.sh
```
The script: creates the Laravel skeleton in `laravel-app/`, copies `laravel-overlay/` into it, writes `.env` (MySQL `nexora`, root/no password, a random service token shared with the AI service), creates the database, runs migrations and the seeder, and builds the Python virtualenv.

If your MySQL root has a password, edit `laravel-app/.env` (`DB_PASSWORD`) and re-run `php artisan migrate --seed`.

> After setup, work **inside `laravel-app/`** and commit it to git (its own `.gitignore` excludes `vendor/` and `.env`). `laravel-overlay/` is only the starting copy.

## Run (2 terminals)

```bash
# Terminal 1 — AI service
cd ai-service && source .venv/bin/activate && uvicorn app.main:app --port 8001

# Terminal 2 — web app
export PATH="/Applications/XAMPP/xamppfiles/bin:$PATH"
cd laravel-app && php artisan serve          # http://127.0.0.1:8000
```
Then process the seeded demo documents (AI service must be running):
```bash
cd laravel-app && php artisan nexora:process
```
If you restart the AI service with a wiped `ai-service/data/`, rebuild its index: `php artisan nexora:process --all`.

Queue: `.env` uses `QUEUE_CONNECTION=sync` (uploads are processed inside the request; simplest for a demo). For async processing set `QUEUE_CONNECTION=database` and run `php artisan queue:work`.

## First run: what to do if something fails

1. Run `cd laravel-app && php artisan test` and paste the failures to me — they will most likely be small (a typo, a Laravel-version difference). That is the honest state of untested code.
2. `php artisan route:list` should list the application routes (documents, search, chat, reviews, users, departments, organizations, audit-logs); `php artisan migrate:status` should show all migrations "Ran".
3. Dashboard shows "AI service: unreachable" → start Terminal 1.
4. Upload shows "failed … ai_auth_failed" → `AI_SERVICE_TOKEN` in `laravel-app/.env` must equal `SERVICE_TOKEN` in `ai-service/.env` (the setup script sets both).
5. `could not find driver` → enable `pdo_mysql` / `pdo_sqlite` in XAMPP's `php.ini`.
6. Scanned PDF shows "no_text" → install tesseract and poppler (see Prerequisites).

See `docs/` for details. Demonstration steps: `docs/DEMO_SCRIPT.md`.

## Optional extras
- **Real LLM:** in `ai-service/.env` set `LLM_PROVIDER=anthropic` (or `openai`), `LLM_API_KEY=...`, `LLM_MODEL=...`, restart the AI service. Without a key the system keeps working in extractive mode and `/health` shows `llm_warning`. Answers are verified against their cited sources; unverifiable ones are withheld. Never commit keys.
- **Docker (untested):** `docker-compose.yml` runs MySQL (port 3307) and the AI service; see the header of that file.
- **Password reset:** "Forgot your password?" on the login page; in development the link is written to `laravel-app/storage/logs/laravel.log`.
- **Acceptance:** `docs/ACCEPTANCE_CHECKLIST.md` shows exactly which items are verified and which need your first run.

## Roles at a glance
| Role | Can do | Cannot do |
|---|---|---|
| **Super Admin** (platform operator) | manage organizations and their status, create Organization Admins, view system health / queues / error logs, handle security incidents and account recovery, read the audit log | open any organization's documents, search results or AI chats |
| Organization Admin | everything inside one organization: departments, users, documents, audit | see other organizations |
| Department Admin / Officer | upload and manage documents in their department | see other departments' documents |
| Reviewer | verify AI answers | change documents |
| Viewer | read, search and ask AI | upload or edit |

## Updating an existing install (when you receive a new zip)
Unzip the new zip somewhere, then from the *new* folder run:
```bash
export PATH="/Applications/XAMPP/xamppfiles/bin:$PATH"
bash scripts/update-mac.sh "/full/path/to/your/existing/folder"
```
It copies the new code over your install (your `.env`, database, uploads and `vendor/` are untouched), runs `php artisan migrate`, and tells you the two follow-up commands (restart the AI service, then `php artisan nexora:process --all`).
